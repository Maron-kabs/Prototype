# 🕌 NoorTracker | Premium Islamic Prayer & Routine Tracker

NoorTracker is a responsive, modern Single Page Application (SPA) designed to help Muslims track their daily structural disciplines, maintain their Salaat consistency, and build a persistent spiritual journal.

## ✨ Features

* **5 Daily Fard Prayers Checklist:** Tracks Fajr, Dhuhr, Asr, Maghrib, and Isha with custom interactive selection states.
* **Dynamic Analytics Ring:** Calculates your daily completion percentage in real-time, giving a instant visual progress update.
* **Persistent Streak Tracker:** Handles date boundaries to compute consecutive days committed to prayer. Saves data securely inside your browser using `localStorage`.
* **Integrated Spiritual Journal:** A dedicated system to log personal Duas (Supplications), Dhikr reflections, or Quran verses read throughout the day.
* **Daily Quran Verse Rotation:** Injects a beautiful, encouraging Ayah onto the home dashboard view upon every fresh page load.
* **Habit Contribution Grid:** Displays an illuminated 60-day visual activity grid tracking your consistency mapping over time.

---

## 🛠️ Tech Stack

* **Frontend Layout:** HTML5
* **Design & Typography:** CSS3 (Featuring a tailored Deep Midnight Emerald Green and Antique Gold theme)
* **Application Scripting:** Vanilla JavaScript (ES6+)
* **Data Layer:** Browser `localStorage` API (Keeps data entirely private to your device without requiring an external server backend)
* **Icon Engine:** FontAwesome Icons v6

---

## 📋 Installation & Local Setup

Since this is a client-side frontend web app, you do not need to install any compilers or background packages:

1. Clone or download this repository to your local device.
2. Open your directory and double-click the `index.html` file to launch it directly inside any modern web browser.
